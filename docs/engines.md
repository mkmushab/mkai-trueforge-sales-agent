# MK-AI Open-Source Engine Layer (`docs/engines.md`)

All open-source engines integrated in Phase 1 follow **Rule 5 (Open-source respect)** and **Rule 9 (Adapters over forks)**:
- Each engine has a thin adapter under `engines/<name>/` and exposes `status()` returning real health.
- Upstream licenses and copyright notices are preserved in `engines/<name>/LICENSE` and `NOTICE.md`.
- Zero AGPL-3.0 code (`firecrawl/firecrawl`) is copied into this repository; Firecrawl is accessed exclusively as a separate service via its MIT MCP/REST interface.
